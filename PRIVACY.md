# Privacidad

- El formulario pide al final un **nombre y un correo**, solo para poder avisar a quien gane el premio.
- Además se guardan las respuestas a las preguntas, la fecha y el camino de preguntas que siguió la persona.
- Todo se envía por correo a quien administra el formulario mediante el servicio Web3Forms; solo esa persona lo lee.
- Se usa únicamente para el premio y para un proyecto del colegio, y no se comparte con terceros.
- Si escribes algo en una casilla de texto, evita incluir nombres de otras personas.

Para pedir que se borren tus datos, escribe a quien te envió el enlace.
