# Privacidad

- El formulario es **anónimo**: no pide nombre, correo, teléfono ni ningún dato que identifique a quien responde.
- Se guardan solo las respuestas a las preguntas, la fecha y el camino de preguntas que siguió la persona.
- Las respuestas se guardan en una hoja de Google privada, a la que solo accede quien administra el formulario.
- Se usan únicamente para un proyecto del colegio y no se comparten con terceros.
- Si escribes algo en una casilla de texto, evita incluir nombres de personas.

Para pedir que se borre una respuesta, escribe a quien te envió el enlace.
